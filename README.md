# /shor landing page

A static one-page landing page for the /shor Discord community.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Customize

- `assets/shor-pfp.gif` = server profile picture
- `assets/shor-banner.gif` = server banner
- `index.html` = copy/content + Discord invite
- `styles.css` = visual design
- `script.js` = intro/reveal/parallax behavior

The Discord invite currently uses `https://discord.gg/ab4pJaY75` from the supplied reference.
